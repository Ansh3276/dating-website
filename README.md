# 💖 Crushly — Find Your Perfect Match

> A modern, AI-powered dating platform built with React, Node.js, and Socket.io. Crushly redefines online romance with curated matches, real-time chat, and a cinematic user experience.

---

## ✨ Features

- **AI-Powered Matching** — Intelligent algorithms that understand real chemistry
- **Real-Time Chat** — Instant messaging with typing indicators, read receipts, and delivery status via Socket.io
- **Cinematic Landing Page** — Scroll-triggered frame animations, parallax quotes, and a premium feel
- **Video Dates** — Built-in video calling for face-to-face connections
- **Smart Profiles** — Multi-step signup with interests, bio, and preference calibration
- **Membership Tiers** — Free, Premium, and Elite membership options
- **Online Presence** — Real-time online/offline status tracking
- **Responsive Design** — Seamless experience across desktop and mobile devices

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- MongoDB (local or Atlas)

### Installation

```bash
# Clone the repository
git clone https://github.com/Ansh3276/dating-website.git
cd dating-website

# Install frontend dependencies
npm install

# Install backend dependencies
cd backend
npm install

# Create .env file in /backend with:
# MONGO_URI=your_mongodb_connection_string
# JWT_SECRET=your_jwt_secret
# PORT=5000

# Start backend server
npm run dev

# In a new terminal, start frontend
cd ..
npm run dev
```

The app will be available at `http://localhost:5173`.
